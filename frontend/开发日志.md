# Tailscale Funnel & Serve 速查表（2025-09 版）

| 目的                         | 一条命令                                                    | 效果                                          |
| ---------------------------- | ----------------------------------------------------------- | --------------------------------------------- |
| **首次启用**（仅一次）       | `tailscale funnel --bg --https=443 http://127.0.0.1:5173`   | 弹出网页点 Enable，生成固定公网地址           |
| **开启公网**                 | `tailscale funnel --bg --https=443 http://127.0.0.1:5173`   | 公网可访问，内网 100.x 也可用                 |
| **关闭公网**                 | `tailscale funnel --https=443 off`                          | 仅停公网，内网 100.x 仍能用                   |
| **彻底清档**                 | `tailscale serve --https=443 off`                           | 连内网映射一起删除，回归干净状态              |
| **换本地端口**               | `tailscale funnel --bg --https=443 http://127.0.0.1:新端口` | 公网地址不变，指向新端口                      |
| **仅暴露后端 API 路径 /api** | `tailscale funnel --bg --set-path /api 8000`                | 公网 `/api` 转发到本地 8000，其余路径不可访问 |
| **查看状态**                 | `tailscale serve status`                                    | 当前映射一览                                  |
